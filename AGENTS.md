# Project Rules & Policies for IDLIX-App

## 1. Confirmation Before Build and Push Policy
- **DO NOT** automatically run `flutter build apk` or push commits (`git push`) to GitHub upon completing code modifications.
- Always ask for and receive explicit user confirmation before starting any release compilation (`flutter build apk`) or pushing commits/releases to GitHub.
- First explain the changes, optimizations, or fixes made to the codebase, and wait for the user to approve before building or publishing.
